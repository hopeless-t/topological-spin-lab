## Frozen generic model

The low-energy target is

```text
H = alpha (kx sigma_y - ky sigma_x) + m(x) sigma_z
```

with Wilson lattice regularization.

Frozen generic parameters for the promoted clean calibration are:

```text
alpha                 1.0 eV·Å
m0                    0.020 eV
wall width            50 Å
xi                    50 Å
lattice spacing       8 Å
transverse sites      100
circumference         800 Å
wall separation       400 Å = 8 xi
Wilson r              0.5
```

No parameter is material-fitted.

## Geometry

Transport is along `y`.

The transverse `x` direction is periodic and contains two well-separated mass
sign changes. The two walls have opposite orientation and therefore opposite
group velocity.

The compensating channel is therefore explicit in the complete lattice problem
instead of being hidden at an open numerical boundary.

The leads and central region use the same Hamiltonian and mass texture for the
clean known-answer baseline.

A clean `T≈1` result is treated as a calibration target, **not** as evidence that
a nontrivial physical device is immune to backscattering.

## Primary observables

The accepted implementation records:

1. scattering unitarity `||S†S-I||`;
2. two-terminal `T_LR`, `T_RL`, `R_LL`, `R_RR`;
3. incoming propagating-channel count per lead;
4. spatial transverse mode identity at each wall;
5. propagating-mode `<sigma_x>`, `<sigma_y>`, `<sigma_z>`;
6. global propagation direction / mode velocity.

A transmission number without spatial channel identity and spin/direction
assignment is insufficient.

EXP-004 calls the spin observable **mode spin expectation / polarization**. It
does not call it a conserved spin current.

## Convergence and acceptance surface

### Discretization and finite-size regime

C10/C11/C12 establish the selected `8 Å / 8 xi` point after sweeps over:

```text
lattice spacing        20, 12.5, 10, 8, 5 Å
wall separation         4, 6, 8, 10 xi
circumference            8, 12, 16, 20 xi
```

The wall-separation and circumference axes are coupled in this geometry because
`circumference = 2 * wall separation`; they are not presented as an independent
two-dimensional scan.

C12 selected `8 Å / 8 xi` because it passed the strict convergence family while
remaining below a 2x dense-`n^3` structural cost proxy relative to the cheaper
`10 Å / 8 xi` point.

### Energy and device length

```text

                        +0.005, +0.010, +0.015
```

All 18 clean points preserve one incoming channel per lead, `T≈1`, `R≈0`, and
unitarity. At the reference length, all six energies also preserve wall,
spin, and velocity identity.

Transmission magnitude changes across the tested clean device lengths only at
floating-point-noise scale.

### Opposite wall orientation

The periodic double-wall lead contains both orientations simultaneously.
Across C13/C14/C15:

```text
canonical wall       <sigma_x> ~ -1, global velocity > 0
opposite wall        <sigma_x> ~ +1, global velocity < 0
```

This is the finite-device realization of the EXP-003 reversal known answer.

### Lead/device mismatch

A half-period central-region mass-texture shift changes clean reflection from
approximately `5.8e-29` to `5.48e-4` while the S matrix remains unitary.

The harness therefore distinguishes physical mismatch reflection from numerical
solver corruption.

### Deliberate S-matrix corruption

Perturbing one S-matrix element by `1e-3` raises the unitarity residual to
approximately `1.0005e-3`, which fails the clean invariant by many orders of
magnitude.
