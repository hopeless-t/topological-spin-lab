## Useful research-method atoms

Strata's development history is a useful example of replacing coarse heuristics with measurable regime-dependent models.

- Fixed counts can be misleading when physical size differs; prefer canonical units with actual meaning.
- Locate performance/behavior knees instead of assuming linear scaling.
- Separate regimes/phases when their dominant mechanisms differ.
- Treat topology and transfer paths as explicit model inputs.
- Preserve an opt-out/baseline path when enabling a new adaptive mechanism so paired comparisons remain possible.
- Distinguish byte-identical/equivalent output checks from performance gains.

## Lab-method implications

For future simulations, record resource topology, exact revision, configuration and regime alongside scientific parameters so computational artifacts can be separated from modeled effects. When introducing adaptive execution, keep a frozen baseline and paired acceptance criteria.

## Boundary

A successful systems optimization or analogy provides no evidence for a topological-spin hypothesis by itself.
