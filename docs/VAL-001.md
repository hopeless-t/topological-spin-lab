# VAL-001 — Regulator Cross-Check

## Status

METHOD DECISION FROZEN / IMPLEMENTATION NOT STARTED

VAL-001 is a numerical-validation lane between the frozen EXP-003 continuum
reference and any later lattice or transport experiment. It is not a new
physical claim.

## Question

Which discrete numerical regulator gives the most trustworthy and reusable
realization of the frozen EXP-003 domain-wall mode?

Candidates:

- single-cone staggered-grid discretization
- Wilson-Dirac lattice regularization

Kwant transport and material-specific AFM modelling remain deferred until this
question is answered.

## Monte Carlo route decision

A 200,000-draw engineering decision analysis varied uncertain weights over
correctness, information gain, numerical-artifact diagnosis, cost efficiency,
future reuse, continuum comparability, and claim safety.

With only full-method choices, Wilson and staggered-grid remained sensitive to
the weighting. Adding a paired regulator pilot produced approximately:

~~~text
paired regulator pilot   93.2%
Wilson directly            4.6%
staggered directly         2.2%
Kwant transport           <0.1%
AFM material model          ~0%
~~~

These are engineering decision-support probabilities produced by subjective
priors. They are not scientific probabilities.

The reproducible script is stored in
research/val001_method_selection.py.

## Pilot calculation matrix

Use the frozen EXP-003 physical reference:

~~~text
alpha  = 1.0 eV·Å
m0     = 0.020 eV
xi     = 50 Å
window = ±12 xi
~~~

Spatial resolutions:

~~~text
N = 61    dx/xi = 0.4    dx = 20 Å
N = 121   dx/xi = 0.2    dx = 10 Å
N = 241   dx/xi = 0.1    dx =  5 Å
~~~

Momentum samples:

~~~text
ky * xi = {-2, -1, 0, +1, +2}
ky      = {-0.04, -0.02, 0, +0.02, +0.04} Å^-1
~~~

A separate 200,000-draw sampling-design Monte Carlo selected
3 grids × 5 ky in about 92.9% of draws.

Run both wall orientations:

~~~text
negative mass -> positive mass
positive mass -> negative mass
~~~

## Wilson parameter pilot

Do not judge Wilson from one arbitrary coefficient.

Use:

~~~text
r = {0.5, 1.0, 1.5}
~~~

A third 200,000-draw decision analysis favored this r sweep combined with the
3-grid × 5-ky design in about 78.4% of draws.

Planned solve count:

~~~text
staggered:
  3 grids × 5 ky × 2 orientations = 30 eigensolves

Wilson:
  3 grids × 5 ky × 2 orientations × 3 r values = 90 eigensolves

total = 120 eigensolves
~~~

## Observables

For each method and resolution, measure:

1. number of in-gap states near the target branch;
2. number of zero-energy crossings;
3. target-mode energy error versus EXP-003;
4. dispersion-slope error;
5. localization-profile error versus EXP-003;
6. spin/chirality error, especially sigma_x;
7. wall-reversal error;
8. convergence versus dx/xi;
9. runtime and peak memory.

## Fail-closed artifact checks

A candidate is rejected if it shows a persistent extra low-energy branch or
zero crossing that does not disappear or cleanly separate from the physical
target under refinement.

A visually convincing localized state is not sufficient.

The pilot must distinguish:

~~~text
target physical branch
extra / duplicate branch
bulk-like state
boundary artifact
~~~

## Decision rule

No winner is predeclared.

1. Reject unresolved duplicate or ghost low-energy modes.
2. Require convergence toward the EXP-003 target.
3. Require correct chirality and wall reversal.
4. Compare continuum error at the finest common resolution.
5. Use runtime and memory only after scientific gates pass.

If both pass, prefer the cleaner artifact margin and convergence before cost.
If neither passes, transport remains deferred and the regulator problem is
re-opened.

## Authority boundary

VAL-001 does not establish a new phase, Chern number, material-specific AFM
physics, quantized transport, or numerical-method superiority before execution.

Until VAL-001 is reviewed:

~~~text
EXP-003 continuum reference = canonical physics target
VAL-001                     = numerical-method validation
EXP-004                     = deferred
~~~
