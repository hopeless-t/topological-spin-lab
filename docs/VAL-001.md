# VAL-001 — Regulator Cross-Check

## Status

**IMPLEMENTED / REVIEWED / TRANSPORT NOT AUTHORIZED**

VAL-001 is a numerical-validation lane between the frozen EXP-003 continuum
reference and any later lattice or transport experiment.

It does not add a new physical claim.

## Question

Which discrete numerical formulation can reproduce the frozen EXP-003
mass-domain-wall mode without silently introducing a second wall-localized
low-energy branch?

The comparison is deliberately between two different regulator families:

1. a Stacey/tangent generalized eigenproblem for stationary spectral
   validation;
2. a conventional Wilson-Dirac lattice Hamiltonian.

## Comparator refinement

The earlier planning document used the broad phrase "staggered-grid". Further
literature review showed that this is too ambiguous.

Hammer and Pötz developed useful staggered space-time schemes for time
propagation, but Pacholski et al. explicitly distinguish those dynamical
schemes from a stationary energy-resolved formulation. VAL-001 therefore uses
the Stacey/tangent generalized eigenproblem from [P-STACEY-2021] as the
stationary comparator.

The 2022 analysis [P-STAG-CRIT-2022] further shows why the exact formulation
must be named: a staggered space-time lattice previously described as
single-cone contains two cones when the enlarged Brillouin zone is counted.

VAL-001 therefore never treats "staggered" as a sufficient provenance label.

## Frozen physical target

All methods are tested against the frozen EXP-003 continuum reference:

~~~text
alpha  = 1.0 eV·Å
m0     = 0.020 eV
w      = 50 Å
xi     = alpha / m0 = 50 Å
window = ±12 xi
~~~

The regulator is the object under test. EXP-003 remains the physics authority.

## Stacey/tangent formulation

The stationary comparator follows the generalized-eigenproblem lineage

~~~text
H psi = E P psi
P = Phi† Phi
~~~

from [P-STACEY-2021].

For this one-dimensional transverse problem, VAL-001 uses a repository-specific
open-boundary reduction:

- Phi averages neighboring closed-grid amplitudes onto midpoint/interface
  locations;
- the derivative is evaluated on the same interfaces;
- outer ghost amplitudes are zero;
- multiplication by Phi† produces Hermitian H;
- P is checked explicitly for Hermiticity and positive definiteness.

This reduction is validated against EXP-003. It is not claimed to be a
verbatim reproduction of every boundary construction in the two-dimensional
source paper.

## Wilson formulation

The Wilson candidate uses the same central Dirac derivative plus

~~~text
(r alpha / a) [1 - cos(k_x a)] sigma_z
~~~

which becomes a nearest-neighbor Wilson mass on the finite grid.

The pilot values are:

~~~text
r = {0.5, 1.0, 1.5}
~~~

[P-WILSON-TI-2017] is the direct condensed-matter prior-art reference for this
regulator family.

## Shared calculation matrix

Spatial resolutions:

~~~text
N = 61    dx/xi = 0.4
N = 121   dx/xi = 0.2
N = 241   dx/xi = 0.1
~~~

Momentum samples:

~~~text
ky * xi = {-2, -1, 0, +1, +2}
ky      = {-0.04, -0.02, 0, +0.02, +0.04} Å^-1
~~~

Both wall orientations are run.

Planned eigensolves:

~~~text
Stacey:
  3 grids × 5 ky × 2 orientations = 30

Wilson:
  3 grids × 5 ky × 2 orientations × 3 r values = 90

total = 120
~~~

SciPy is borrowed for the Hermitian and generalized-Hermitian eigensolvers.
VAL-001 does not implement its own dense linear-algebra solver.

## In-gap state classification

A low-energy state is classified by where its probability lives.

~~~text
target wall region:
  |x| <= 3 xi

outer-boundary region:
  |x| >= 9 xi

wall-localized:
  weight >= 0.9 in target wall region

boundary artifact:
  not wall-localized and weight >= 0.9 in outer-boundary region

other:
  neither
~~~

The physical target is the wall-localized branch that maximizes overlap with
the frozen EXP-003 analytic state.

A **ghost wall mode** is any additional wall-localized in-gap mode beyond that
target.

Boundary artifacts are reported separately. They are not relabeled as
fermion doublers.

## Special rule at ky = 0

The finite hard-wall problem contains a target-wall state and an
outer-boundary state that can become nearly degenerate at zero momentum.

Individual eigenvectors inside a degenerate subspace are not unique.

VAL-001 therefore does not grade the raw eigenvectors at ky=0. It projects the
near-zero subspace onto the target-wall region and diagonalizes that projector
inside the subspace. This produces localized wall and boundary combinations
before overlap, spin, and ghost classification are applied.

This rule prevents an arbitrary eigensolver basis from creating a false FAIL.

## Hard acceptance gates

Each regulator variant is checked for:

~~~text
matrix Hermiticity                   <= 1e-12 eV
target energy error                  <= 1e-8 eV
target overlap                       >= 0.98
target wall weight                   >= 0.98
target edge contamination            <= 1e-4
sigma_x error                        <= 1e-8
finest-grid profile L1 error         <= 0.08
ghost wall modes                     = 0
boundary artifacts                   <= 1
unclassified in-gap modes            = 0
profile error                        monotone under refinement
~~~

The Stacey metric additionally requires:

~~~text
P Hermiticity residual               <= 1e-12
minimum eigenvalue(P)                >= 1e-8
~~~

These are validation gates, not claims that the numerical method is exact.

## Red Team

The failure detector is tested against a deliberately unregulated central
difference calculation, Wilson r = 0.

At nonzero ky that naive discretization produces two wall-localized in-gap
branches rather than the single EXP-003 target branch.

The VAL-001 harness must classify at least one of them as a ghost. If it does
not, the validation harness itself is considered broken.

~~~text

        ↓

~~~

This is a role assignment for this benchmark, not a universal ranking of

The transport candidate remains **unauthorized for EXP-004** until a separate
Scientific Contract explicitly authorizes the transport experiment.

## Decision rule

No single universal method winner is required.

First apply the scientific/numerical hard gates.

If the Stacey generalized eigenproblem passes, the passing regulator with the
smallest continuum-profile error becomes the **stationary spectral validator**.

Among passing Wilson variants, the r value with the smallest finest-grid
profile error becomes the **conventional-lattice transport candidate**.

The roles are intentionally separated when possible:

~~~text
continuum truth
    ↓
independent stationary validator
    ↓
conventional lattice candidate
    ↓
future transport experiment
~~~

A method is not allowed to be its own only validator.

VAL-001 does not itself authorize EXP-004 transport.

## Monte Carlo decision support

Earlier 200,000-draw engineering Monte Carlo selected the paired regulator
pilot over immediately committing to Wilson, a staggered method, Kwant
transport, or a material-specific model.

A second sensitivity layer is now reproducible in
`research/val001_threshold_sensitivity.py`.

It performs 300,000 draws over deliberately broad plausible acceptance
thresholds for overlap, profile error, localization, energy error, edge
contamination, and spin error.

Its question is:

> If reasonable validation strictness moves, does the regulator conclusion
> remain stable?

The output is engineering robustness under the stated threshold model. It is
not a physical probability and is not part of scientific evidence.

The reviewed 300,000-draw sensitivity run produced:

~~~text
Stacey/tangent   0.9629367
Wilson r=0.5     0.6009000
Wilson r=1.0     0.2809567
Wilson r=1.5     0.0570333
~~~

These values mean only that, under the stated randomized threshold model,
Stacey and then Wilson r=0.5 remain PASS across a larger fraction of plausible
validation strictness. They are not probabilities that either method is
physically correct.

## Authority boundary

VAL-001 may decide only which numerical roles are justified by this frozen
domain-wall benchmark.

It does not establish:

- a new topological phase;
- a Chern number;
- an NdBi or AFM-TI material model;
- quantized transport;
- disorder robustness;
- superiority of either regulator outside the tested problem;
- authorization to begin EXP-004.
