# Scope

## Current scope

`topological-spin-lab` is a small computational-physics laboratory for effective
models of topological and spin-dependent electronic states on consumer hardware.

The first experiment, EXP-001, is a known-answer reference for a generic
massless two-dimensional surface Dirac Hamiltonian.

## Current non-claims

The project does not currently claim to:

- reproduce NdBi from first principles;
- predict a real material;
- demonstrate an experimental spin current;
- establish an edge state without a model that can support one;
- replace DFT, ARPES, STM, transport measurements, or laboratory validation.

NdBi is an inspiration and a future comparison target, not the identity of the
EXP-001 model.

## Expansion rule

A capability is added only when a defined experiment requires it and when that
experiment has explicit acceptance criteria.
