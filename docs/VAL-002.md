# VAL-002 — NdBi model-adequacy validation

## Canonical status

**SCIENTIFIC / MODEL-ADEQUACY CONTRACT FROZEN**  
**MODEL IMPLEMENTATION / FITTING:** **NOT AUTHORIZED**  
**Date:** 2026-10-07

VAL-002 asks:

> What is the **smallest explicit model state space** that can reproduce the
> source-conditioned low-energy NdBi surface observables required by current
> spectroscopy/material references, while preserving a traceable separation
> from the frozen generic L0 known-answer model?

VAL-002 does not ask which Hamiltonian looks most plausible.

## Why this gate exists

EXP-004 has passed as a **generic clean known-answer transport calibration**.
That result establishes the numerical transport harness for its frozen L0 model.
It does not establish that the L0 state space is adequate for NdBi.

The central material risk is **state-space under-resolution**, not merely
lattice/discretization error.

No reduction of lattice spacing can create degrees of freedom that are absent
from the model, such as:

- multiple surface branches / folded sectors;
- orbital character;
- magnetic-sublattice or q-order structure;
- surface inversion-breaking terms distinct from one scalar magnetic mass;
- surface/domain/termination context;
- bulk/surface hybridization information.

Every material observable must be serialized with context before value:

```text

```

Missing context must be recorded as unknown, not silently guessed.

## C01 target contract

C01 freezes **target classes**, not a fitted Hamiltonian.

### T1 — domain / combined-symmetry response — REQUIRED

Source context: S1, NdBi (001), AF phase.

The model interface must be capable of representing at least two declared AF
surface-domain/symmetry contexts with different Dirac responses:

```text
S-broken / out-of-plane AF-order component   -> gapped Dirac response
S-preserving / surface-parallel AF order     -> gapless Dirac response
```

Acceptance at this stage is **representability plus correct qualitative
ordering**, not a free fit to an arbitrary gap for each domain.

A model with only one context-free scalar `m` parameter does not satisfy T1
merely because the user can manually set `m=0` or `m!=0`; the domain/symmetry
variable and its coupling rule must be explicit in the model contract.

### T2 — AF surface branch + spin structure — REQUIRED

Source context: S3.

The candidate must expose enough observables to compare:

- the relevant AF-state surface branches;
- opposite spin polarization of the observed pair;
- antisymmetry of spin polarization about the source-defined TRIM;
- full vector spin expectation where the model provides it, not only one scalar
  spin label.

A candidate that reproduces energies but cannot produce the corresponding
spin-resolved observables is inadequate.

### T3 — quantitative spin-polarized Dirac gap — REQUIRED

Source context: S4.

Frozen experimental target:

```text
gap at the reported surface Dirac point     17 ± 2 meV
reported DFT reference                      ~12 meV
```

The `17 ± 2 meV` experimental interval is the measurement target. The `~12 meV`
DFT value is an independent material-reference comparison, not a second value
to average into the experiment.

For a later fitted material model, the default quantitative acceptance rule is:

> the model-predicted source-matched Dirac gap must overlap the experimental
> uncertainty interval `[15, 19] meV`, unless a preregistered uncertainty model
> justifies a different rule before fitting.

C01 itself does not perform the fit.

### T4 — surface/bulk identity — REQUIRED

Source context: S4.

The candidate/oracle interface must distinguish the targeted surface state from
bulk-derived states through at least one explicit representation:

- surface spectral weight;
- layer-resolved localization;
- projection onto a declared surface subspace;
- or a material-oracle quantity demonstrably equivalent for this target.

Energy agreement without surface/bulk identity does not satisfy VAL-002.

### T5 — surface-magnetic-order sensitivity — REQUIRED

Source context: S4.

The model must support a declared perturbation/context corresponding to loss or
suppression of the relevant surface magnetic order, and the target gap must not
remain an unconditional fixed constant.

Required qualitative relation:

```text
relevant surface magnetic order present      -> gapped target state
surface magnetic order suppressed/absent     -> gap closes or is strongly suppressed
```

The implementation must define what model variable represents this perturbation
before comparing results.

### T6 — q-order / surface-state multiplicity — REQUIRED AS DISCRIMINATOR

Source context: S2.

Magnetic q-order must be an explicit declared context variable before a
material-wide NdBi claim becomes eligible.

The material reference reports different surface-state multiplicities and bulk
topological node classes across 1q/2q/3q configurations and surfaces. Therefore:

- a candidate may be validated first on one preregistered q-order slice;
- it must not present that slice as universal NdBi;
- a model that has no place to represent q-order cannot pass a later
  material-wide adequacy gate.

C01 does not require fitting every q-order simultaneously.

## Downstream target frozen but excluded from C01

### T7 — termination-dependent 1D edge state — DEFERRED

Source context: S5.

Later boundary validation must be able to represent the discriminator:

```text
odd step / magnetic-domain-wall edge on FM termination, T < TN
    -> localized 1D edge-mode signal

comparable step on AFM termination
    -> no corresponding enhanced edge-state signal

FM step above TN
    -> edge-state signal disappears
```

T7 is scientifically important but intentionally does not block the first
uniform-surface reduced-model gate. Mixing it into C01 would conflate surface
band adequacy with boundary transport/localization physics.

## Model ladder

VAL-002 retains the previously audited hierarchy:

```text
L0  frozen generic 2x2 Dirac + scalar mass known answer
L1  symmetry-derived low-order surface k.p model
L2  minimal spin x orbital x AFM/folding reduced model
L3  DFT+U+SOC / Wannier material-reference model
```

The ladder is a hypothesis order, not a mandate to reach L3.

## Complexity rule

Promote the **smallest adequate** level.

```text
try L0 against representability contract
    if impossible -> serialize exact failures
try L1 only after allowed terms are symmetry-derived
    if target class still impossible -> serialize failures
introduce L2 sectors only for failures that require them
check L2 against L3/material source observables
```

Parameter count is not evidence. A larger model is penalized unless it repairs
a preregistered failure of a smaller one.

## C01 acceptance states

Each target receives one of:

```text
REPRESENTABLE
NOT_REPRESENTABLE
CONTEXT_MISSING
SOURCE_EXTRACTION_PENDING
NOT_APPLICABLE_AT_THIS_LEVEL
```

`PASS` for a model level is forbidden until every C01 **REQUIRED** target is
`REPRESENTABLE` and every required context field is explicit.

A target marked `REQUIRED AS DISCRIMINATOR` may be evaluated on one declared
slice at the first fitted stage, but the limitation must remain in the claim
ceiling.

## Failure-biopsy rule

When a model level fails:

1. name the exact missing observable/context capability;
2. distinguish missing state-space dimension from wrong parameter value;
3. minimize the failure to the smallest counterexample;
4. add only the minimum symmetry- or oracle-justified structure capable of
   representing it;
5. retain the failed lower model as a control.

Do not silently mutate L0.

## Numerical/data extraction rule

Before parameter fitting begins, source-derived quantitative datasets must be
materialized with provenance.

For every digitized or transcribed value record:

- source figure/table/text locator;
- axis units and calibration;
- extraction method;
- experimental uncertainty if supplied;
- any additional digitization uncertainty;
- surface/domain/q-order context;
- immutable source identifier.

A visually estimated plot coordinate without uncertainty/provenance cannot
become a hard acceptance threshold.

## Claim ceiling

VAL-002 C01 freezes a material-adequacy question and target contract only.

It does not establish:

- an NdBi Hamiltonian;
- L1 or L2 coupling matrices;
- a successful material fit;
- an NdBi transport result;
- a material-specific domain-wall conductance;
- a QAH plateau;
- a conserved spin current;
- reproduction of the 2026 edge-localized state.
